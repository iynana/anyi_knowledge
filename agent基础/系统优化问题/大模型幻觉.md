大模型幻觉：模型生成了听起来合理、但实际上是错误、虚构或无法验证的信息。
+ 事实性幻觉：捏造不存在的对象
+ 逻辑性幻觉：前后矛盾
+ **指令性幻觉**：不遵循用户指令
+ **上下文幻觉**：忘记前面聊过什么


# 产生幻觉的原因

+ 原理：大模型本质上是根据上下文去预测下一个词是什么。这个过程是 “统计意义上的最优匹配”，而非 “基于事实的逻辑推导”。 
+ 训练：大模型是通过数据去训练出来的，而提供的数据的规模和范围是有限的
+ 推理：上下文过长，模型注意力分散（$softmax$归一化后长度增加，导致注意力分散），位置编码退化（现在采用的编码方式RoPE大多基于sin,cos这样的周期函数，序列拉长后会出现位置混淆），噪声积累（无关信息增加）

# 如何缓解幻觉？
- RAG 检索增强，通过精确检索真实文档，让模型基于可靠数据源生成内容，而非凭空猜测
- 提示词工程： 通过精准提示词引导模型 “基于检索内容回答”，并明确要求 “不确定时注明”
- 模型微调：使用高质量、领域对齐的数据集对模型进行微调， 提升特定领域的事实准确性
