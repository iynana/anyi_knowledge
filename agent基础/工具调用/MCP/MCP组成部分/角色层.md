+ **MCP Server**：负责按 MCP 规范封装工具，对外提供标准化接口，和底层大模型完全解耦（Tools工具，Resources只读资源，Prompts标准化提示词）；
	+ 1️⃣ 定义 tool（name + schema + handler）  
	+ 2️⃣ 注册 tool 到 server（放入 registry）  
	+ 3️⃣ tools/list 返回这些 tool（让client可以进行 tool discovery）  
	+ 4️⃣ tools/call 能调用对应 handler
+ **MCP Client**：作为中间层，一头对接 MCP Host（大模型应用），一头对接 MCP Server，**核心作用是协议转换**—— 把大模型的指令转成 MCP 标准格式，也把工具结果转成大模型能识别的格式；
+ **MCP Host**：运行大模型的==应用==（如 ChatGPT 客户端、自定义 AI 助手），只需内置 MCP Client，就能无缝调用所有 MCP Server 上的工具，不用关心工具的具体实现和模型差异。
