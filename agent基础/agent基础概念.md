Agent ≈ LLM（推理） + memory（记忆）+ tools（工具）+ plan（规划）
- LLM 模型负责思考和表达
- Memory 保持上下文连贯和长期喜好
- Tools 工具负责执行
- plan 具备规划拆解、多步推理与自我纠错能力
	- 推理技术：CoT 思维链（单线分布推理）、ToT思维树（多优线分布推理）
	- 规划范式：ReAct（边执行边规划）（复杂任务成功率高）（局部贪心；延时高）、Plan-and-Execute（先规划后执行）（有全局性）（局部错误难处理）、Reflexion（评估结果是否符合预期）（降低错误率）（增加大模型调用次数）

**LLM和agent**二者区别
**LLM 核心**是推理和表达，核心能力是语义理解、文本生成、逻辑推理
**Agent**负责决策、目标推进、工具执行，会通过目标拆解、自主规划、工具调用、反馈迭代、多步任务闭环
