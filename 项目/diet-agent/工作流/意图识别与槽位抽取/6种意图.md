`DietOrchestratorService#handleTurn` 在 `INTENT_REVISED` 后按最终 `intent` 分发：

| 路由目标                | 处理函数                 | 后续链路                          |
| ------------------- | -------------------- | ----------------------------- |
| MEAL_RECOMMENDATION | handleRecommendation | 合并槽位 → Clarify → 推荐流水线        |
| CLARIFY_NEEDED      | handleRecommendation | 同上（规则层可能 ASK）                 |
| MEAL_ADJUST         | handleAdjust         | 合并槽位 → excludeMealIds → 推荐流水线 |
| MEAL_PLAN           | handlePlan           | 合并槽位 → phase=PLAN → 推荐流水线     |
| HEALTH_RISK         | handleHealthRisk     | 保守文案，不走推荐                     |
| OTHER               | handleChitchat       | 固定引导文案，不调用 LLM                |
