## 1. 一轮对话完整链路
```
POST /api/v1/diet/chat
        │
        ▼
┌─ DietOrchestratorService.dietChat ─────────────────────────────┐
│ 1. 生成 traceId                                                │
│ 2. loadOrCreate SessionState                                   │
│ 3. openTrace（ThreadLocal TraceScope）                         │
│ 4. sessionLock 串行化同 session 请求                           │
│ 5. handleTurn                                                    │
└────────────────────────────────────────────────────────────────┘
        │
        ▼
handleTurn 内部：
  appendMessage(user)
  PERSONAL 空库检查 → 提前返回
  IntentAgent → IntentRevise → switch 路由
```

## 2. 路由分发（switch intent）

`DietOrchestratorService#handleTurn` 在 `INTENT_REVISED` 后按最终 `intent` 分发：

| 路由目标                | 处理函数                 | 后续链路                          |
| ------------------- | -------------------- | ----------------------------- |
| MEAL_RECOMMENDATION | handleRecommendation | 合并槽位 → Clarify → 推荐流水线        |
| CLARIFY_NEEDED      | handleRecommendation | 同上（规则层可能 ASK）                 |
| MEAL_ADJUST         | handleAdjust         | 合并槽位 → excludeMealIds → 推荐流水线 |
| MEAL_PLAN           | handlePlan           | 合并槽位 → phase=PLAN → 推荐流水线     |
| HEALTH_RISK         | handleHealthRisk     | 保守文案，不走推荐                     |
| OTHER               | handleChitchat       | 固定引导文案，不调用 LLM                |

## 3. 推荐主链路（handleRecommendation → completeRecommendation）

```
SlotMergeService.merge()
        |
        v
ClarifyAgentService.decide()
    ├── ClarifyRuleService.missingSlots() → 规则判 ASK/READY
    ├── ASK → ClarifyAgent 生成追问 → completeAsk → 返回 CLARIFY 响应
    └── READY → completeRecommendation
        |
        v
completeRecommendation（推荐流水线）：
	① MealSearchService.search()        → JSON_OVERLAPS 召回 ≤50
	② MealRankService.rank()            → 7维打分 Top10，exclude 已推荐 ID
	③ ranked 为空                       → 空库提示
	④ RecommendResponseAgent            → Top3 理由 + speechText
	⑤ RiskGuardService.check()          → 合规拦截，必要时改写
	⑥ 更新 lastRecommendations + save SessionState
	⑦ appendMessage(assistant) + 返回 ANSWER 响应（含餐食卡片）
```

**调整链路（MEAL_ADJUST）**
```
handleAdjust:
    merge slots
    excludeMealIds = state.lastRecommendations（累计已推荐 ID）
    phase = RECOMMEND → completeRecommendation(..., excludeMealIds)
```

Rank 层过滤 `excludeMealIds`，实现「换一批」不重复推荐。


## 4. 会话状态机（SessionPhase）

| Phase     | 含义   | 触发时机            |
| --------- | ---- | --------------- |
| START     | 初始   | 新建会话            |
| CLARIFY   | 澄清等待 | Clarify ASK 返回后 |
| RECOMMEND | 推荐中  | 槽位足够进入推荐        |
| PLAN      | 多餐规划 | MEAL_PLAN 路由    |

`SessionState` 维护：
- `phase`：初始START、澄清等待CLARIFY、推荐中RECOMMEND、多餐规划PLAN
- `currentIntent`：当前/上一轮确认意图
- `slots`：多轮累积 7 维槽位
- `lastRecommendations`：已推荐 mealId 列表（换一批排除用）
- `sourceMode`：PERSONAL / PUBLIC 数据源隔离

==Phase 写入 DB，便于排查会话卡在哪个阶段。==

## 5. 并发与一致性

- **会话级锁**：`ConcurrentHashMap<sessionId, lock>` + `synchronized`，同 `session` 串行写状态
- **Orchestrator 独占写 SessionState**：Agent 不直接写 DB
- **Trace 贯穿整轮**：`try-with-resources TraceScope`，close 时写入到 `diet_request_trace`
