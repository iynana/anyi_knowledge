+ 第一层：IntentAgent 解析兜底，大模型返回失败或者json解析错误，用关键词识别
+ 第二层：intentReviseService 状态感知矫正
	+ 用户输入含健康风险关键词：即使 LLM 置信度较低也走保守风险链路
	+ intent=MEAL_ADJUST 且 lastRecommendations 为空：降级为 MEAL_RECOMMENDATION
	+ intent=MEAL_RECOMMENDATION 且 confidence < 0.4：降级为 CLARIFY_NEEDED
+ 第三层：Orchestrator 路由层兜底
	+ PERSONAL 空库：无个人餐食时直接返回引导文案，跳过意图识别后的推荐链
	+ HEALTH_RISK 分支：不走推荐，返回 RiskGuardService.conservativeMessage()
	+ OTHER 分支：固定引导文案，不调用 
	+ LLM推荐链路内 ClarifyRule：即使 LLM 判 MEAL_RECOMMENDATION，必要槽位缺失，规则层仍会 ASK
