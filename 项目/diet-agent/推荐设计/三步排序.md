1. 用 MySQL `JSON_OVERLAPS` 按餐次、心情、场景、健康诉求等槽位召回最多 100 条候选。
	+ 系统先把用户的餐次、心情、场景、健康诉求等槽位转换成 **JSON 数组**
	+ 通过 MySQL **`JSON_OVERLAPS`** 检索候选餐食
	+ 同一维度内只要**命中任一标签**即可
2. 计算七个槽位所有的标签命中率，按得分降序取 Top 10。
	+ 候选命中的用户标签数 ÷ 用户的标签数
3. 进行MMR多样性重排后，取Top 3后交给大模型，大模型只负责生成推荐理由。
	+ 采用 `jaccard` 得分计算相似度
	+ 标签命中率即相关性
	+ 循环选取多样性重排top3，`0.75*相关性 - 0.25*相似度` 这个值最大，相关性的算法和第二轮一样，相似度用 `jaccard` 得分
