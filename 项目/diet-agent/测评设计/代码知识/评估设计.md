## 1. 评估体系概览

本项目构建了 **「Trace 驱动 + 规则评分 + LLM-as-Judge + 用户反馈」** 四层评估体系：
```
diet_request_trace（trace_json + 人工标注 gold）
        │
        ▼
EvaluationService.evaluate(timeRange)
   ├── 规则指标（从 trace 自动解析）
   ├── LLM Judge 指标（可选，EvaluationJudgeAgent）
   └── 用户反馈分（recommend_feedback 按 session 归因）
        │
        ▼
EvaluationReport（区间汇总 + 单条明细）
```
API：`POST /api/v1/diet/evaluations`

## 2. 评估方式
### 2.1 批量离线评估
请求体 `EvaluationRequest`：
- startAt / endAt：评估时间窗口
- includeLlmJudge：是否启用 LLM-as-Judge（默认可选）
- limit：最大 trace 条数（默认 1000）

流程：
1. 按时间范围从 `diet_request_trace` 拉取 trace
2. 批量加载同 session 的 `recommend_feedback`
3. 逐条 parseTrace → 计算指标 → 加权总分
4. 输出 `EvaluationReport`（区间平均 + 单条 `TraceEvaluationResult` 明细）

### 2.2 人工标注（Gold Label）

通过 Trace 标注页/API 写入：
- expected_intent
- expected_slots
- expected_clarify_action
有标注的 trace 才参与 intentAccuracy / slotAccuracy / clarifyNecessityAccuracy 计算；无标注返回 null，不影响其他指标。

### 2.3 LLM-as-Judge

`EvaluationJudgeService` 调用 EvaluationJudgeAgent（qwen-turbo），输入 trace 摘要：
- predictedIntent / predictedSlots / predictedClarifyAction
- finalReply / recommendationCount
- safetyComplianceByRule / hallucinationFreeByRule（背景信息，Judge 不重复评）

输出 1-5 分：
- explanationQuality：解释质量
- naturalness：自然度

Judge 失败返回 null，不影响规则分计算。

### 2.4 用户反馈

`recommend_feedback` 表记录用户对推荐的操作：
- rating（1-5 星）→ 归一化到 0-1
- action（LIKE/DISLIKE/SWITCH 等）→ 映射满意度分

当前按 **sessionId 归因**（反馈表无 traceId，同 session 反馈共享）。

## 3. 评估指标
### 3.1 规则指标（0-1 分制）

| 指标                       | 计算方式                           | 依赖                           |
| ------------------------ | ------------------------------ | ---------------------------- |
| intentAccuracy           | expected vs predicted 完全一致     | 人工标注 expected_intent         |
| slotAccuracy             | 7 维槽位集合匹配比例                    | 人工标注 expected_slots          |
| clarifyNecessityAccuracy | ASK/READY 完全一致                 | 人工标注 expected_clarify_action |
| tokenCost                | AGENT_CALL totalTokens 累加（原始值） | trace 自动                     |
| tokenCostScore           | ≤1000→1.0；≥3000→0；中间线性衰减       | trace 自动                     |
| latencyMs                | duration_ms（原始值）               | trace 自动                     |
| latencyScore             | ≤3s→1.0；≥8s→0；中间线性衰减           | trace 自动                     |
| fallbackRate             | FAILED 或 errorMessage → 1.0    | trace 自动                     |
| fallbackScore            | 未 fallback → 1.0               | trace 自动                     |
| safetyCompliance         | 最终回复不含禁用短语                     | trace 自动                     |
| hallucinationControl     | responseIds ⊆ rankedIds        | trace 自动                     |
| multiTurnConsistency     | MEAL_ADJUST 时新推荐未命中 excludeIds | trace 自动                     |
### 3.2 LLM Judge 指标（1-5 分 → 归一化 0-1）

| 指标                 | 说明                |
| ------------------ | ----------------- |
| explanationQuality | 是否说明推荐理由，理由是否贴合需求 |
| naturalness        | 表达是否自然，非机械拼接      |

### 3.3 用户反馈指标

| 指标                | 说明                  |
| ----------------- | ------------------- |
| userFeedbackScore | session 下多条反馈的平均满意度 |

## 4. 总分加权
单条 trace 总分（百分制）：

| 组成部分              | 权重  | 来源                                     |
| ----------------- | --- | -------------------------------------- |
| ruleScore         | 60% | 上述规则指标平均（跳过 null）                      |
| llmJudgeScore     | 10% | explanationQuality + naturalness 归一化平均 |
| userFeedbackScore | 30% | 用户反馈平均                                 |

若某组成部分缺失（如无标注、无反馈、未开 Judge），按 **实际存在权重归一**，避免缺失维度拉低总分。

## 5. 评估报告结构（EvaluationReport）
```
startAt, endAt
traceCount          — 参与评估 trace 数
labeledCount        — 至少有一个 gold 标注的 trace 数
averageScore        — 区间平均总分（百分制）
metricAverages      — 各指标区间平均
results[]           — 单条 TraceEvaluationResult 明细
  ├── traceId, sessionId, createdAt
  ├── score, ruleScore, llmJudgeScore, userFeedbackScore
  ├── metrics（全部指标明细）
  └── detail（predicted vs expected + judgeReason）
```

## 6. Trace 解析关键事件映射

EvaluationService 从 trace_json 提取事实：

| 事件                                     | 提取字段                               |
| -------------------------------------- | ---------------------------------- |
| INTENT_REVISED                         | intent, slots                      |
| SLOTS_MERGED                           | slots（优先）                          |
| CLARIFY_DECISION                       | clarifyAction                      |
| ADJUST_CONTEXT_RESOLVED                | excludeMealIds, intent=MEAL_ADJUST |
| MEAL_RANKED                            | ranked[].id                        |
| RESPONSE_AGENT_RESULT / RESPONSE_READY | speechText, displayBlocks[].id     |
| AGENT_CALL                             | totalTokens 累加                     |

## 7. 设计亮点

1. **规则与 Judge 职责分离**：安全/幻觉/意图/槽位走规则，解释质量和自然度走 LLM Judge，避免 Judge 重复评已覆盖维度
2. **缺失标注不惩罚**：无 gold label 的指标返回 null，不参与平均，适合渐进式标注
3. **Trace 即评估数据源**：无需额外埋点，评估完全复用线上 Trace
4. **可开关 Judge**：`includeLlmJudge=false` 时纯规则+反馈评估，降低成本
