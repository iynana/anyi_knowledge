## 评估指标
### 1 规则指标（0-1 分制）

| 指标                           | 计算方式                           | 依赖                               |
| ---------------------------- | ------------------------------ | -------------------------------- |
| ==intentAccuracy==           | ==expected vs predicted 完全一致== | ==人工标注 expected_intent==         |
| ==slotAccuracy==             | ==7 维槽位集合匹配比例==                | ==人工标注 expected_slots==          |
| ==clarifyNecessityAccuracy== | ==ASK/READY 完全一致==             | ==人工标注 expected_clarify_action== |
| tokenCost                    | AGENT_CALL totalTokens 累加（原始值） | trace 自动                         |
| tokenCostScore               | ≤1000→1.0；≥3000→0；中间线性衰减       | trace 自动                         |
| latencyMs                    | duration_ms（原始值）               | trace 自动                         |
| latencyScore                 | ≤3s→1.0；≥8s→0；中间线性衰减           | trace 自动                         |
| fallbackRate                 | FAILED 或 errorMessage → 1.0    | trace 自动                         |
| fallbackScore                | 未 fallback → 1.0               | trace 自动                         |
| safetyCompliance             | 最终回复不含禁用短语                     | trace 自动                         |
| hallucinationControl         | responseIds ⊆ rankedIds        | trace 自动                         |
| multiTurnConsistency         | MEAL_ADJUST 时新推荐未命中 excludeIds | trace 自动                         |
### 2 LLM Judge 指标（1-5 分 → 归一化 0-1）

| 指标                 | 说明                |
| ------------------ | ----------------- |
| explanationQuality | 是否说明推荐理由，理由是否贴合需求 |
| naturalness        | 表达是否自然，非机械拼接      |

### 3 用户反馈指标

| 指标                | 说明                  |
| ----------------- | ------------------- |
| userFeedbackScore | session 下多条反馈的平均满意度 |

## 2. 总分加权
单条 trace 总分（百分制）：

| 组成部分              | 权重  | 来源                                     |
| ----------------- | --- | -------------------------------------- |
| ruleScore         | 60% | 上述规则指标平均（跳过 null）                      |
| llmJudgeScore     | 10% | explanationQuality + naturalness 归一化平均 |
| userFeedbackScore | 30% | 用户反馈平均                                 |

若某组成部分缺失（如无标注、无反馈、未开 Judge），按 **实际存在权重归一**，避免缺失维度拉低总分。
