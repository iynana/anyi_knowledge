# 长期记忆
长期记忆首先是取决于我们**输入**的个性化信息，这一块首先输入的内容其实不是很多，当问答时，我们对长期记忆的语义相似度阈值定的比较高，定为0.8，避免不相关的长期记忆被召回，因此最终**召回**的信息也不会很多。所以长期记忆的长度相比于其他部分是很少的，可以忽略不计。

# 短期记忆
- 我们在选择短期记忆时，只会选取最近最新的会话内容，目前设定的是选取最近的 64k token 会话内容。假设平均一轮对话 3000~6000 token，那么我们的短期记忆窗口大约可完整地容纳15 轮对话。在我们团队的应用场景下，其实足够使用了
- 虽然我们的大模型用的是Qwen-plus，其支持的最大输入是百万token，但短期记忆的窗口token数不设置的太大，主要是为了**降低成本**。Qwen-plus 的计费方式是**阶梯式的计费模式**
	- 如果我们单次请求的输入token数在128k以下，输入价格（每百万token）是0.8元
	- 如果我们单次请求的输入token数大于128k小于256k，则输入价格（每百万token）是2.4元
	- 也就是说如果输入的token数超出128k，那么价格就变为原先的三倍
	- 因此为了不达到收费的第二个区间，所以尽量让短期记忆的窗口在满足需求的情况下尽可能小
