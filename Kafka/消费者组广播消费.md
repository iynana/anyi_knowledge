Kafka 的广播消费是通过**多个不同的消费者组订阅同一个 topic**实现的。
+ 同一topic
+ 不同group id

```java
@KafkaListener(topics = "voucher", groupId = "voucher-order-service")
public void createOrder(String message) {
    // 创建订单
}

@KafkaListener(topics = "voucher", groupId = "voucher-notification-service")
public void sendNotification(String message) {
    // 发送通知
}
```
