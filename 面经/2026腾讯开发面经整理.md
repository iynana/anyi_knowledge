# 2026 腾讯开发面经整理

> 更新时间：2026-10-08  
> 范围：公开可检索的 2026 年腾讯及腾讯旗下业务（WXG、腾讯云、腾讯音乐、腾讯文档）开发岗面经。覆盖后端、前端、AI/大模型开发；同类问题已合并，按提问类型而非原面经逐篇罗列。题目编号用于复习索引。

## 八股

### Java、并发与运行时

1. Java 的多态如何实现？动态分派发生在什么阶段？
2. 线程池的核心参数分别是什么，如何按 CPU 密集型和 IO 密集型任务设置？
3. 线上 OOM、频繁 Full GC 分别可能由什么引起，如何定位和优化？
4. JVM 的新生代、老生代如何回收？常见 GC 算法各有什么适用场景？
5. `ThreadLocal` 的实现和内存泄漏风险是什么？在线程池中怎样正确清理？
6. `volatile` 解决什么问题？它和锁、CAS 的边界分别是什么？
7. 进程、线程、协程的差异是什么，共享资源时如何保证安全？
8. Go 的 goroutine 为什么轻量？GMP 模型和 channel 底层解决了什么问题？
9. C++/Java/Go 的内存管理和并发模型有哪些关键差异，语言如何选型？

### 数据库、缓存与中间件

10. ACID 与事务隔离级别分别是什么，会产生哪些并发现象？
11. MVCC 如何工作？行锁、表锁以及间隙锁分别在什么情况下出现？
12. B 树、B+ 树的结构差异是什么，MySQL 为什么常用 B+ 树做索引？
13. 慢 SQL 怎样从监控、执行计划、索引和数据分布逐层排查？
14. Redis 常用数据结构及其业务场景是什么？遇到 big key 怎样处理？
15. Redis 主从复制如何运作？Redis 与 MySQL 的一致性如何保障？
16. Redis 的 IO 模型是什么；Lua 脚本为什么能保证原子性，集群跨 slot 为什么受限？
17. RabbitMQ/Kafka/RocketMQ 如何选型？死信队列适合处理什么问题？
18. Kafka 如何保证投递语义，消费者重复消费如何治理？
19. ES 索引与检索的基本过程是什么，什么场景下用 ES 而不是数据库查询？
20. 服务发现和 Nacos 心跳机制如何工作？

### 网络、操作系统与工程化

21. TCP 与 UDP 的差异、适用场景，以及 UDP 仍被使用的原因是什么？
22. HTTPS 握手如何建立信任，证书被伪造或中间人攻击如何防范？
23. `select`、`poll`、`epoll` 的差异是什么？epoll 的 LT/ET 如何取舍？
24. `TIME_WAIT` 与 `CLOSE_WAIT` 分别意味着什么？大量堆积如何排查？
25. Linux 上 CPU 长期飙高时，如何定位到进程、线程、热点调用和根因？
26. Maven 的生命周期、依赖管理与 SNAPSHOT/release 的区别是什么？
27. JWT 与 Session 的工作方式、撤销能力和适用边界是什么？
28. 常见设计模式如何落到实际项目中？DDD 的聚合、领域服务和边界如何划分？

### 前端与客户端基础

29. 浏览器从 URL 输入到页面呈现经过哪些阶段，哪个环节通常最耗时？
30. 虚拟 DOM、浏览器渲染流程、React 的更新机制分别解决什么问题？
31. 闭包、事件循环、宏微任务和 `Promise` 异常传播如何解释？
32. `useState` 闭包陷阱、`useEffect` 依赖项和 `useLayoutEffect` 的区别是什么？

35. Web 性能应看哪些指标（FCP、LCP、CLS 等），首屏优化有哪些手段？

## 项目

1. 介绍一个最有亮点的项目：背景、你负责的部分、技术难点、量化结果分别是什么？
2. 你的项目为什么选用当前技术栈？有哪些替代方案，最终为何不选？
3. 微服务如何拆分；拆分前后解决了什么问题，如何处理跨服务调用和数据边界？
4. 讲一次性能优化：如何发现瓶颈、验证根因、实施改动并衡量收益？
5. 项目如何保证代码质量、发布质量和可观测性？除 ESLint 外有哪些机制？
6. 大文件分片上传的完整链路是什么？如何计算 hash、断点续传、秒传和清理临时分片？
7. 计算文件 hash 造成主线程卡顿时如何优化？Web Worker 的通信与故障降级怎么做？
8. 虚拟列表如何实现，如何处理可变高度、滚动定位和渲染抖动？
9. 组件库怎样将逻辑层与 UI 层分离，并实现 PC/移动端复用？
10. 协同白板如何用 CRDT/Lamport 时钟处理乱序操作？Lamport 的局限是什么，为何不改用向量时钟？
11. EventEmitter/EventBus 为什么可能造成内存泄漏，如何定位和修复监听器生命周期？
12. 项目中 Redis 如何使用？缓存更新失败、缓存穿透、击穿、雪崩分别如何处理？
13. 讲一个你设计的表结构：为何这样建模，索引如何设计，后续如何演进？
14. 服务注册发现、配置管理和健康检查在项目中怎样落地？
15. 介绍 Agent/RAG 项目的请求链路；模型、embedding、chunk、rerank 如何选择？
16. 多 Agent 项目的编排如何完成？任务失败、超时、中断和重试如何处理？
17. 模型输出必须引用真实证据 ID 时，系统如何校验并阻止幻觉引用？
18. Agent 工具调用怎样做白名单、参数校验、审计与降级？
19. 项目中的 AI 编程工具如何使用，在哪些环节有效、哪些环节仍需人工把关？
20. 遇到代码重构范围大或跨团队协作阻塞时，如何拆解、沟通并控制风险？

## 场景

### 分布式一致性与高并发

1. 秒杀库存如何防止超卖，并保证同一商品不被多个用户同时下单成功？
2. 如何设计分布式锁？按用户 ID 加锁时会不会造成热点阻塞，怎样改进？
3. Redis 节点宕机导致锁未释放怎么办？如何权衡可用性和正确性？
4. 支付请求超时、网络丢包或 ACK 丢失时，如何避免重复支付？
5. 如何设计接口幂等，防止重复提交和消息重复消费？
6. 数据库更新成功但删缓存失败会发生什么？用消息队列重试后又有旧值写入时，怎样避免错误删除新缓存？
7. 设计一个限流器；令牌桶、滑动窗口和漏桶如何选型？
8. 设计商品搜索与秒杀系统，如何处理流量突刺、热点和降级？
9. 管理 5 台以上服务时，负载均衡、扩缩容、故障转移和发布回滚如何做？

### 消息、任务与数据处理

10. 用消息队列执行删除失败重试时，怎样处理消息乱序、重复和最终一致性？
11. 如何设计多线程任务执行及后续任务衔接，如何控制并发度、取消和错误传播？
12. 最近 30 天用户消费数据如何设计表结构并写出高效聚合查询？
13. 分库分表后如何选择分片键，如何处理跨分片查询与深分页？
14. 面对高并发写入，如何优化数据库访问与数据实时处理链路？

### 前端、协同与稳定性

15. 多轮对话助手连续使用一天可能发生内存泄漏，如何监控、定位并修复？
16. Worker 崩溃时，前端系统如何降级、恢复任务并保持用户体验？
17. 如何实现图片懒加载与 WebP 降级；预加载、懒加载分别适合什么时机？
18. 如果白板的低时钟操作晚到，如何保证协同状态最终一致？
19. 文件上传服务如何管理分片，既支持秒传又避免完整文件和碎片的重复存储？

### AI/Agent 工程落地

20. Agent 的 Function Calling 出现不存在的函数、参数格式错误或语义不合法时，如何分层容错？
21. 模型反复调用同一工具进入循环时，如何检测、终止并保留可恢复的中间结果？
22. RAG 知识库如何不停机更新；索引构建、版本切换和回滚怎么做？
23. 长上下文采用摘要与向量检索后，如何衡量摘要的信息损失是否可接受？
24. 金融/跨境汇款 Agent 出现超时或工具失败时，如何设计确认、补偿、审计与人工兜底？
25. 并发 Agent 会话如何隔离状态、控制资源并保持可观测性？

## 复习优先级

1. **后端主线**：事务/MVCC、Redis 一致性、幂等与支付、消息可靠性、线程池与 GC、慢 SQL 与线上排障。
2. **项目表达**：每个项目至少准备一次技术选型、一次故障或性能优化、一次权衡与指标证明。
3. **AI 方向**：RAG 评估、上下文管理、工具调用安全、多 Agent 编排和失败恢复。
4. **前端方向**：React/Hooks、渲染与性能、大文件上传、协同编辑与稳定性。
