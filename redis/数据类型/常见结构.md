# Dict 哈希表
![[Pasted image 20260405172308.png]]
Dict 哈希表 底层存在 两条哈希表（数组+链表实现哈希表）
一条哈希表存储的是当前数据，另外一条哈希表一般是空，在哈希表扩容 Rehash 时会使用到

Dict 哈希表会扩容或者收缩，此时就需要重新计算key存储的位置，也称为rehash
在rehash过程中，如果用户想要请求数据，
- 新增操作，则直接写入 ht\[1\] 即新哈希表
- 查询、修改、删除，则会在 ht\[1\] 新哈希表 和 ht\[0\] 旧哈希表 上依次查找并执行

# ZipList 压缩列表

一种连续内存空间的双端链表，因存储格式而节省空间，但由于连续内存
如果元素太多，内存不容易分配，效率低，所以当元素过多时，都会转为另外一种数据结构
且 ZipList 压缩列表存在连锁更新的问题

# QuickList 快速列表

一种双向链表，每个节点是一个压缩列表

# SkipList 跳表
无论是 ZipList 还是 QuickList，在访问时，本质都是一个个遍历的访问，他们在查找首尾结点时性能高。但是要做范围查找时，只能一个一个遍历直到范围的起始点。

SkipList 跳表 是一种多层链表
- 元素按 score 分数进行升序排序存储
- 一个节点内可能包含多个指针，每个指针的跨度不同。链表遍历慢的原因就是因为指针的跨度为1
- 当做范围查找时，利用高层级的指针，快速跳过大量无关节点，快速定位到范围的起始点
- 跳表通过牺牲少量内存空间（存储多层指针），换取了更高效的范围查找性能
