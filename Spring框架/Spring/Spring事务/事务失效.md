1. **非 public 方法**：Spring 默认只对 public 方法进行事务增强，如果注解在 protected、private 或包可见的方法上，事务不会生效。
2. **同类内部调用**：如果一个类的内部方法调用另一个带有 @Transactional 的方法，且调用是通过 this 直接调用（而非代理对象），则事务不会生效，因为调用没有经过 Spring 的代理对象。
3. **异常被捕获后未抛出**：事务默认仅在方法抛出未捕获的运行时异常或错误（Error）时回滚。如果方法内部捕获了异常并自行处理（未抛出），事务不会回滚。
4. **数据库引擎不支持事务**：如 MySQL 的 MyISAM 引擎不支持事务，即使注解正确，也无法回滚。
5. **事务管理器配置错误**：未正确配置事务管理器或数据源。
