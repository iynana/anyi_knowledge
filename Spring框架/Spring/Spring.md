一个轻量级 Java 企业级开发框架，核心目标是**解耦**和**简化开发**。
核心框架：
+ **IoC（控制反转）**：将传统上由程序代码直接操控的对象创建和依赖关系的控制权转移给容器，由容器负责对象的生命周期和依赖关系管理。实现方式是依赖注入 DI。
+ **AOP（面向切面编程）**：将横切关注点（日常、事务、安全等）与业务逻辑分离，提高模块化。允许开发者在不修改源代码的情况下，对业务方法进行增强。Spring AOP 基于动态代理实现。
	1. 当目标类实现了至少一个接口时，Spring 使用 JDK 动态代理，生成一个实现相同接口的代理类，调用方法时实际进入方法处理器，并织入增强逻辑。
	2. 当目标类没有实现接口时，Spring 使用 CGLIB 代理，生成目标类的子类作为代理，通过重写方法实现增强。CGLIB 在运行时动态生成字节码，效率较高，但无法对 final 方法进行代理。
+ **事务管理**：Spring提供了一致的事务管理接口，支持声明式和编程式事务。开发者可以轻松地进行事务管理，而无需关心具体的事务API。
+ **MVC框架**：Spring MVC是一个基于Servlet API构建的Web框架，采用了模型-视图-控制器（MVC）架构。
