# 区别
+ HTTP是明文传输，HTTPS是通过TLS握手加密传输
+ HTTP端口80，HTTPS端口443
+ HTTPS需要CA证书，保证服务器身份的真实性（根CA证书在本地，服务器在TLS中提供证书链）

# HTTPS的TLS加密过程
+ 通过 ECDHE 方式，生成共享密钥
+ 服务器发送数字证书，并对握手信息进行签名
+ 客户端验证数字证书的证书链，并用证书里的公钥验证签名
+ 用共享密钥派生对称密钥，进行加密通信

非对称加密速度很慢，所以只有TLS用，通信用对称加密

非对称加密场景（不能提取共享密钥）：
+ 区块链
+ 数字签名
+ TLS

对称加密场景：
+ 数据量大
+ 高频通信
