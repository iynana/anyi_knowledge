- **ConcurrentHashMap**：高效线程安全的哈希表。
- **CopyOnWriteArrayList 和 CopyOnWriteArraySet**：适用于读多写少的场景，写时复制。
- **BlockingQueue** 接口的实现类 ArrayBlockingQueue、LinkedBlockingQueue、PriorityBlockingQueue 等，支持阻塞操作。
- **Hashtable**，但是锁住了整个表
- ConcurrentSkipListMap 和 ConcurrentSkipListSet：基于跳表的并发有序集合。
- ConcurrentLinkedQueue 和 ConcurrentLinkedDeque：基于 CAS 的无锁非阻塞队列。
