# 回表
``select id,age,name from tb.student where age = 1;``

当查询语句中 以二级索引的列为 查询条件时，会先走二级索引树，查到叶子节点取到主键值，再回到主键索引树上，以刚取到的主键值去匹配，找到叶子节点取得 id、age、name上述过程中查询主键索引树的这个过程叫回表，需要尽量避免回表。

# 覆盖索引
``select id,age from tb.student where age = 1;``

当查询语句中 以二级索引的列为 查询条件时，且**只查询了 id 和 age 在二级索引树的叶子节点中就存在着主键id和age的数据**，因此只需要查询二级索引树，此时不需要再去主键索引树中查询，上述过程就利用了 覆盖索引 提高效率。
