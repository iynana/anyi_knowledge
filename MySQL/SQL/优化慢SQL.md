+ 分析：利用EXPLAIN针对慢查询日志定位到的SQL语句分析性能（type,key,row,extra）

# 优化

## 1.业务需求优化，SQL语句优化
+ 直接查第10000页这种不合理需求
+ 深度分页查询,用延迟关联的方式记录上一次查询的id，直接从上一次查询后开始查询
+ select *

## 2.结构优化
+ 建立覆盖索引
+ 表中字段选择合适的数据类型

## 3.架构优化
+ **读写分离**： 将读操作和写操作分离到不同的数据库实例，提升数据库的并发处理能力。
+ **分库分表**： 将数据分散到多个数据库实例或数据表中，降低单表数据量，提升查询效率。但要权衡其带来的复杂性和维护成本，谨慎使用。
+ **缓存机制**： 使用 Redis 等缓存中间件，将热点数据缓存到内存中，减轻数据库压力。
+ **冷热数据分离**：数据的时间空间上的访问频率，分别存储在不同介质或系统中，以优化性能和成本。
