时间窗口：按时间**分桶**，24 小时频控`count = CMS(t) + CMS(t-1) + ... + CMS(t-23)`，可以采用环形桶。

```
请求
 │
 ▼
CMS 快速判断
 │
 ├── count << threshold
 │      → 直接放行
 │
 ├── count > threshold
 │      → 拒绝
 │
 └── count ≈ threshold
        │
        ▼
     Redis 精确计数
```
