```java
// key -> 缓存节点
Map<Integer, Node> cache;

// 双向链表，维护节点最近访问顺序
DoublyLinkedList list;

// 缓存容量
int capacity;
```
- **查 `get(key)`**：先通过 `HashMap` O(1) 找到节点；找到后，将节点从双向链表的原位置删除，再移动到**链表头部**，表示该节点最近被访问，最后返回 `value`。
    
- **写 `put(key, value)`**：
    - **Key 已存在**：更新 `value`，然后将节点从原位置删除并移动到**链表头部**。
    - **Key 不存在**：创建新节点，加入 `HashMap`，同时插入**链表头部**。
    - **容量已满**：插入新节点前/后淘汰**链表尾部**节点，并从 `HashMap` 中删除对应 Key，因为尾部节点就是**最久未访问的节点**。

一句话面试版：

> **LRU 通过 HashMap + 双向链表实现，HashMap 用于 O(1) 定位节点，双向链表维护访问顺序；查询时将访问节点移动到链表头部，写入时将新增或更新节点移动到头部，容量满时淘汰链表尾部最久未访问的节点，因此 get 和 put 都能做到 O(1)。**
